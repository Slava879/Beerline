Прототип системы автоматического планирования маршрутов сервисных инженеров.
Принимает заявки (CSV / ручной ввод), геокодирует адреса, раскладывает по мастерам с учётом навыков, оборудования, окон клиентов и смен мастеров, строит карты маршрутов.

## Содержание

## 1. Быстрый старт

### 1.1. Что нужно
| Компонент | Версия |
|---|---|
| Python | 3.10+ |
| PostgreSQL | 14+ (с расширением `uuid-ossp`, при необходимости) |
| Node.js | 18+ |
| npm | 9+ |

### 1.2. Клонирование
```bash
git clone <https://github.com/Slava879/Beerline.git> my_project
cd my_project
```

### 1.3. Переменные окружения
Создай .env в корне
```bash

# backend
DATABASE_URL=postgresql+asyncpg://Beerline1:Beerline1784591263@localhost:5432/appdb
JWT_SECRET=67c5...
LOCATIONIQ_API_KEY=pk....
MAPBOX_TOKEN=pk....

VITE_API_URL=http://127.0.0.1:8000
VITE_WS_URL=ws://localhost:8000
 ```
### 1.4. Backend
```bash
 pip install -r backend/requirements.txt
 uvicorn backend.app.main:app --reload --port 8000
```
### 1.5. Frontend
```bash
cd frontend
npm install
npm run dev
# и откройте http://localhost:5173
```

### 1.6. Первый прогон
Открой UI → «Выбрать участок» → загрузите заявки через csv файл, где имя файла загрузится как имя участка, выберите участок, заполните адрес офиса (город/улица/дом).

Добавь мастеров/инженеров  

Нажми «Распределить заявки» — вылезет alert с вопросом перекодировать ли адреса заново или нет (при первом запуске адреса не геокодированы, так что первое распределение или распределении при соглашении перекодировать все адреса заново займет достаточно долгое время (при 60 заявка это примерно 4-5 минут))

В распределенных карточках появятся кнопки этапов (Выехал / Начал / Завершил), кнопка i — почему заявка назначена или не назначена.
